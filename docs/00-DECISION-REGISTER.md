# 00. 已冻结产品决策登记表

本文件用于防止开发过程中重新讨论已确认事项。除非正式发起变更流程，否则以下决策不可由开发人员或 Codex 自行修改。

## 1. 范围

- V1 为完整商用版，分三阶段开发和验收。
- 不做视频生成。
- 不做在线支付，不记录线下收款、成交金额、退款或发票。
- 不做自动发布，只做渠道导航、渠道适配和发布链接即时检测。
- 不做网页端 AI 自动化和真实官网截图。
- 不做多语言，全部简体中文。
- 不做团队、子账号或多人协作。
- 不做复杂文章版本历史。

## 2. 用户与套餐

- 单账号可管理多个主体，数量由套餐控制。
- 注册只需手机号、昵称、验证码和密码。
- 注册后可立即登录但待审核，审核前不可调用 AI。
- 登录支持密码和短信。
- 无套餐用户只能创建一个主体草稿。
- 套餐由后台发布和手动开通。
- 同一账号同一时间只允许一个生效套餐。
- 套餐有效期、额度和保留规则后台配置。
- 月度次数按套餐开通日重置。
- 试用套餐由管理员审核时决定是否发放，发放后立即生效。

## 3. GEO 检测

- 固定 8 模型：DeepSeek、豆包、通义千问、腾讯混元、百度文心、Kimi、智谱 GLM、讯飞星火。
- 官方 API 检测，用户在套餐允许范围内选择模型。
- 每个问题每个模型每次调用一次，独立新会话。
- 支持联网时默认开启；降级策略按模型配置。
- 中性提示词，不向模型透露待检测主体。
- 每个模型独立得分，综合分等权。
- 单模型成功率至少 80% 才是正式模型分。
- 至少 6 个正式模型才是正式综合分。
- 失败模型不按 0；正常回答但未提及主体按 0。
- 管理员不能改分。

## 4. 评分

自然探索型六维固定权重：提及 25%、推荐 20%、排名 15%、准确度 20%、倾向 10%、引用 10%。

品牌指向型不计提及和排名，权重：推荐 1/3、准确度 1/3、倾向 1/6、引用 1/6。

GEO 等级：卓越、优秀、一般、较弱、薄弱。

曝光指数：提及率 40%、推荐率 25%、排名表现 20%、模型覆盖率 15%；等级为极高、高、中、较低、低；不是实际曝光人数。

## 5. 关键词与问题库

- 关键词生成数量由套餐上限控制。
- 可选短关键词、长尾关键词、地区关键词。
- 三项不是必选，也不是互斥；地区词可同时是短词或长尾。
- 全部不选时生成通用关键词。
- 蒸馏不按固定数量或比例，按意义保留、合并、删除或标记低价值。
- 蒸馏结果必须用户确认。
- 问题库数量由套餐控制，AI 不强制填满。
- 问题一个主分类、多个辅助标签。
- AI 判断优先级和自然／品牌类型，用户可修改。
- 问题库确认后才能检测。

## 6. 文章与图片

- 所有文章必须关联主体。
- 支持直接生成或先大纲。
- 文章长度由内容决定，不设硬字数。
- 每成功生成完整正文或渠道稿扣 1 文章额度。
- 局部修改使用局部次数；整篇优化扣文章额度。
- 优化时原稿和优化稿临时对比，用户二选一，只保存选中稿。
- 首次质量检测免费，质量低不阻止导出。
- 文章和图片均自动审核，疑似进入人工审核。
- 豆包生成图片，每成功 1 张扣 1 图片额度。
- 普通缩放裁剪免费，AI 扩图／重构扣图片额度。
- 取消视频功能。

## 7. 报告和分享

- 报告首页完整展示综合分、口碑分、曝光指数、模型分、六维、竞品和趋势。
- 明细按问题排列，每问题下展示 8 模型。
- 默认关键片段，可展开完整回答。
- 不生成证据卡片或图片。
- 支持 PDF、Word、Excel。
- 默认显问品牌，套餐可开放白标。
- 分享为完整报告，不做模块勾选；可设密码、有效期、关闭，并下载 PDF。

## 8. AI 助手

- 固定 DeepSeek。
- 读取当前主体，不读取其他主体。
- 不保存聊天记录。
- 不直接执行检测、文章或图片任务。
- 成功回复消耗套餐对话次数。

## 9. 后台和安全

- 自定义管理员角色和权限。
- 超级管理员拥有密钥最高权限，其他角色完全无权限。
- 密钥保存后只显示掩码，无法回看原文。
- 高风险操作可配置确认、密码或双人审批。
- 默认高危操作双人审批。
- 管理员协助查看为只读；普通情况需用户单次授权，超级管理员可因安全／违规／故障强制查看。
- 使用记录细粒度保存；额度和审计日志长期保留。

## 10. 技术

- Next.js＋TypeScript＋Ant Design。
- Python 3.12＋Django 5.2 LTS＋DRF。
- Celery＋Redis。
- PostgreSQL 16。
- Docker Compose＋Nginx＋Gunicorn。
- 模块化单体，不上微服务或 Kubernetes。
- 第一版任务进度轮询。
