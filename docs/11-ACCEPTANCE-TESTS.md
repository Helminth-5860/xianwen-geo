# 11. 验收标准与测试计划

## 1. 验收原则

- 功能“页面能打开”不等于完成。
- 每项验收必须覆盖正常、失败、取消、重试、权限和额度回滚。
- 真实外部 API 未通过验收的功能不得标记完成。
- 所有核心业务规则必须有自动化测试。
- V1 最终验收分阶段，但上线前必须通过全链路验收。

## 2. 测试层级

- 单元测试：业务规则、评分、额度、权限、解析函数
- 集成测试：数据库、Redis、Celery、COS Mock、API 适配器 Mock
- 合约测试：8 模型、DeepSeek、豆包真实接口
- 端到端测试：用户和后台完整流程
- 性能测试：并发、队列、数据库和状态轮询
- 安全测试：越权、SSRF、XSS、CSRF、密钥、额度一致性
- 恢复测试：备份、任务重试和故障恢复

## 3. 阶段一验收：账号与套餐

### 3.1 注册

- 手机号、昵称、验证码和密码可注册。
- 重复手机号被拒绝。
- 注册验证码成功后立即登录，状态为 approved/active，不需要管理员批准首次登录。
- 无效验证码不创建账号；历史 pending/rejected 状态继续兼容且不会被自动迁移。
- 密码和验证码不出现在日志。

### 3.2 登录

- 密码和短信均可登录。
- 错误次数达到限制后触发锁定或限流。
- 忘记密码可重置。
- 退出其他设备即时生效。

### 3.3 审核

- 管理员可通过、拒绝并填写原因。
- 审核结果通知符合规则。
- 审核通过无套餐用户只能创建一个主体草稿。

### 3.4 套餐

- 后台可创建、发布、下架套餐。
- 已开通用户绑定套餐快照。
- 同一用户不能有两个 active 套餐。
- 试用发放后立即生效。
- 套餐申请状态完整。

## 4. 额度验收

### 4.1 流水不变量

- 任何额度变动产生流水。
- 无接口可直接改余额。
- 可用和冻结不出现负数。
- 流水幂等键重复不产生第二次变动。

### 4.2 冻结与结算

- 任务创建成功同时冻结。
- 队列提交失败自动回滚。
- 成功扣除、失败返还。
- 部分成功按实际数量结算。
- 用户取消只返还未开始部分。

### 4.3 并发测试

模拟多个请求同时消耗最后余额：最多一个或允许数量成功，不能透支。

### 4.4 月度重置

- 按开通日重置。
- 31 日锚点在短月份使用最后一天。
- 套餐到期不重置。
- 每主体次数独立。
- AI 助手次数按账号。

## 5. 主体模块验收

- 后台动态主体类型和字段正确展示。
- 必填字段未完成只能保存草稿。
- AI 补充结果带来源且需确认。
- 未确认内容不能参与关键词生成。
- 风险主体进入审核。
- 修改主体创建新版本。
- 旧报告绑定旧版本不变。
- 降级主体归档且不删除历史数据。
- 删除进入回收站并可恢复。

## 6. 文件和资料验收

- 支持规定文件格式和网页链接。
- 文件扩展名、MIME 和签名校验。
- 存储不足时禁止上传。
- 解析后必须确认。
- 修改解析文本创建新版本。
- 未确认资料不能用于文章。
- SSRF 测试阻止 localhost、私网和元数据地址。
- 删除／恢复和保留期正确。

## 7. 关键词验收

### 7.1 类型

- 短关键词、长尾关键词、地区关键词均可独立选择。
- 三项均不选时生成通用关键词。
- 地区关键词可同时是短词或长尾。
- 地区来自主体或临时添加。

### 7.2 数量和编辑

- 不超过套餐上限。
- AI 少生成时不报假成功数量。
- 手动编辑不扣重新生成次数。
- 重新 AI 生成成功才扣次数。
- 保存后创建新版本。

## 8. 蒸馏验收

- 返回保留、合并、删除、低价值和理由。
- 不强制固定保留比例。
- 不同地区有效词不被误合并。
- 用户确认前不能生成问题库。
- 手动修改不扣 AI 次数。

## 9. 问题库验收

- 数量不超过套餐上限。
- AI 不强制填满上限。
- 主分类一个、辅助标签多个。
- AI 优先级可人工调整。
- 自然／品牌指向类型可人工调整。
- 用户确认前不能检测。
- 单次选题不超过套餐上限。

## 10. 8 模型适配器验收

每个模型逐一完成：

- 正常调用
- 中文回答
- 独立新会话
- 实际模型版本记录
- 联网请求和实际状态记录
- 引用标准化
- 超时和重试
- 429 处理
- 无效密钥处理
- Token／用量记录
- 成本估算
- 并发限制
- 暂停后停止新任务
- 原始回答完整保存

任一模型未通过，不计“8 模型接入完成”。

## 11. GEO 检测任务验收

- 用户选择套餐允许的模型。
- 提交前显示正确预计点。
- 服务端重新计算，不能通过篡改前端少扣点。
- 任务在后台执行，关闭页面不停止。
- 8 模型状态可轮询。
- 单模型失败不影响其他模型。
- 用户取消按规则处理。
- 模型暂停后不自动替换。
- 队列按套餐优先级和提交时间。
- 排队超时自动退款。

## 12. GEO 评分单元测试

### 12.1 提及

- 完整名命中。
- 已确认别名命中。
- 英文名命中。
- 唯一产品命中。
- 非唯一产品不命中。
- 未提及整题为 0。

### 12.2 推荐

分别验证 100、75、40、0。

### 12.3 排名

分别验证第 1、2–3、4–5、6–10、10 后和正文提及。

### 12.4 准确度

验证 100、75、40、0，并绑定主体资料快照。

### 12.5 倾向

验证 100、75、50、25、0。

### 12.6 引用

验证官方／政府、主流媒体、普通网站、无法核验和无引用。

### 12.7 品牌指向型

提及和排名为 N/A，四项按比例计算；不进入 GEO 综合分。

## 13. 模型和综合分门槛

- 20 个问题成功 16 个：80%，正式模型分。
- 成功 15 个：75%，临时模型分。
- 6 个正式模型：正式综合分。
- 5 个正式模型：临时综合分。
- 失败模型不按 0。
- 正常未提及问题按 0。

## 14. 曝光指数验收

- 公式和权重准确。
- 无提及时提及率、推荐率、排名表现合理为 0。
- 模型覆盖率按本次成功模型。
- 少于 6 个正式模型只显示临时指数。
- 等级区间边界正确。
- 页面明确“不是实际曝光人数”。

## 15. 报告验收

- 首页包含全部确定模块。
- 明细按问题分组。
- 默认关键片段，支持展开完整回答。
- 不生成逐条证据图片。
- PDF、Word、Excel 可导出。
- 历史报告不可修改。
- 管理员不能改分。

## 16. 复测和趋势

- 快速复测沿用原问题／模型。
- 调整复测可重新选择。
- 每次新建独立报告。
- 问题和模型完全一致才计算涨跌。
- 主体版本变化允许比较并标注。
- 评分规则版本变化不计算正式涨跌。

## 17. 改善策略验收

- 每份不可变报告的第一次成功策略免费；失败不占用免费成功名额。
- 可选 7／30／90／自定义周期。
- 内容为建议而非任务管理。
- 原文不可编辑，备注可编辑。
- 重新生成成功扣次数，失败不扣。
- 推荐主题跳转文章页但不自动扣文章额度。
- 重生成创建新的不可变版本，历史正文保留；并发和幂等重试不得双扣。

## 18. AI 助手验收

- 固定 DeepSeek。
- 只读取当前主体。
- 切换主体后上下文切换。
- 不保存聊天记录。
- 不执行任务或扣其他额度。
- 成功回复扣一次对话次数，失败不扣。
- 尝试读取其他主体、提示词或密钥时拒绝。
- 数据库只保留最小 usage metadata，不存在消息、回复或 transcript 正文列。
- 网络失败、畸形回复和并发重复请求不得扣费或重复调用 provider。

## 19. 文章资料包验收

- 公开网页、主体资料和上传文件可配置使用。
- 后台文章类型限制来源范围生效。
- 资料来源可访问和相关性核验。
- 关键冲突等待用户选择。
- DeepSeek 不得生成资料包外的伪造引用。
- 每篇文章绑定资料包快照。

## 20. 文章生成验收

- 必须关联主体。
- 直接正文和大纲模式可用。
- 首次大纲免费。
- 重新大纲扣次数。
- 正文成功扣 1 文章额度，失败返还。
- 字数不设硬限制。
- AI 推荐深度可修改。
- 自动保存当前稿。

## 21. 文章质量和优化验收

- 首次自动质量检测免费。
- 六项权重准确。
- 等级边界准确。
- 质量低不阻止导出。
- 修改后复检扣次数。
- 局部优化扣局部次数。
- 整篇优化扣文章额度。
- 原稿和优化稿临时对比。
- 用户选择后只保留选中稿。
- 无文章版本恢复入口。

## 22. 文章审核验收

- 自动审核正常内容。
- 疑似内容进入人工审核。
- 审核中不可复制、导出或发布。
- 系统误判返还／补偿。
- 用户违规不返还。
- 每篇一次免费人工复核。
- 超级管理员可额外开放。

## 23. 渠道适配验收

- 可批量选择多个渠道。
- 提交前显示正确文章额度。
- 每个成功稿扣 1，失败返还。
- 原文章不被覆盖。
- 每个渠道稿自动质量检测。
- 后台模板版本影响新稿，不影响旧稿。

## 24. 图片验收

- AI 推荐配图和手动入口均可用。
- 用户确认后才调用。
- 参考图可来自主体资料库或临时上传。
- 尺寸和风格预设生效。
- 每成功一张扣 1 图片额度。
- 普通裁剪不扣，AI 扩图扣。
- 生成后转存 COS。
- 自动／人工审核和责任退款正确。
- 图片可选择临时或主体图库。
- 原图、压缩、渠道图和 ZIP 下载正常。

## 25. 发布检测验收

- 公开可访问且标题／正文匹配：成功。
- 无效或不匹配：失败。
- 登录、验证码、反爬或网络异常：暂时无法判断。
- 保存单次记录。
- 不存在定时自动复查任务。

## 26. 报告分享与白标

- 默认显问品牌。
- 套餐无白标权限时不能隐藏显问品牌。
- 白标权限时主体配置生效。
- 分享完整报告，无模块勾选。
- 密码、有效期和关闭生效。
- 分享页可下载 PDF。
- 分享令牌不可枚举，数据库不存明文。

## 27. 后台验收

### 27.1 权限

- 自定义角色和菜单／动作权限生效。
- API 端点不能通过直接请求绕过。
- 客户数据范围生效。
- 只有超级管理员能管理密钥。

### 27.2 高风险操作

- 普通确认、密码验证和双人审批可配置。
- 发起人不能自审。
- 审批后载荷不能篡改。

### 27.3 客户记录

- 唯一负责人。
- 联系记录和待办。
- 站内提醒。
- 客户状态可配置但历史状态不可删除。

### 27.4 提示词

- 草稿不会影响线上。
- 固定案例、手动和历史脱敏测试。
- 发布只影响新任务。
- 可回退。

## 28. 性能验收

### 28.1 API

- 不含外部 AI 的普通 API P95 < 800ms（目标值，按真实环境确认）。
- 异步任务提交 2 秒内返回任务 ID。

### 28.2 并发

至少模拟：

- 50 个用户同时轮询任务状态。
- 多用户同时提交检测但受套餐和全站并发限制。
- 8 模型中一个持续超时。
- 大量排队任务的超时退款。

### 28.3 数据库

- 流水并发无负余额。
- 模型调用明细分页查询可接受。
- 报告按问题分组加载不一次返回全部大文本。

## 29. 安全验收

- 用户 A 无法访问用户 B 的主体、报告、文章和图片。
- 普通管理员无法调用超级管理员密钥 API。
- CSRF 防护。
- CORS 限制。
- 密码和验证码不在日志。
- SSRF 阻止私网地址和重定向绕过。
- 上传伪造扩展名被拒绝。
- 模型输出 XSS 被清洗。
- 分享密码爆破限流。
- 管理员协助查看只读。
- 注销数据清理和匿名化。

## 30. 故障与恢复验收

- Redis 短时不可用：Web 给出可理解错误，永久数据不丢失。
- Worker 重启：已入库任务可重试或恢复，不重复扣额度。
- 外部 API 大面积失败：任务部分成功并正确退款。
- PostgreSQL 备份可恢复到隔离环境。
- COS 文件和数据库引用能一致恢复。
- 严重告警可送达超级管理员。

## 31. 上线阻断条件

以下任一存在不得上线：

- 额度可被重复扣除或出现负数。
- 用户越权访问他人数据。
- API 密钥可从前端或普通接口读取。
- 8 模型适配未全部真实验收。
- DeepSeek 内容或豆包图片功能未验收却在前端开放。
- 报告评分与规则文档不一致。
- 任务关闭页面后丢失。
- 文件／报告通过应用服务器直接长期传输导致不可用。
- 备份未做恢复测试。
- 内容审核无法拦截明显违规测试样本。

## 32. Definition of Done

一个开发任务只有同时满足以下条件才完成：

- 代码完成并评审
- 数据迁移完成
- 权限校验完成
- 额度规则完成
- 异常和幂等完成
- 单元／集成测试通过
- OpenAPI 更新
- 前端状态和错误文案完成
- 审计日志完成（适用时）
- Staging 验收通过
