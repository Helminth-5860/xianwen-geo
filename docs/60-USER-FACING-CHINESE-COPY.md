# 普通用户界面中文产品语言规范

## 适用范围

本规范适用于登录、注册、工作台、主体档案、关键词、问题库、检测、报告、优化、内容资产、套餐和账户等普通用户可见页面。超级管理员后台可按管理职责展示必要的专业信息，但不能把后台原始信息直接透传到普通用户页面。

## 统一产品术语

| 统一名称      | 使用场景                                         |
| ------------- | ------------------------------------------------ |
| GEO 总览      | 当前主体的整体经营与 GEO 表现概览                |
| 主体档案      | 企业或个体工商户资料及主体管理                   |
| 关键词中心    | 智能关键词、自定义关键词、关键词蒸馏和关键词资产 |
| 问题库        | 问题生成、管理和参与检测设置                     |
| AI 可见度检测 | 使用已选问题评估主体在各 AI 平台中的可见度       |
| GEO 洞察      | 检测报告、历史报告对比、曝光指数和竞品对比       |
| 优化方案      | 根据检测结果生成并管理改善建议                   |
| 知识图谱建设  | 主体、地图、官网和媒体信号建设                   |
| 内容资产      | 内容库、图片库、视频库和自定义资料库             |
| 待处理        | 尚未开始或正在等待处理的用户业务状态             |
| 处理中        | 系统正在完成用户操作                             |
| 已完成        | 操作已成功完成并可查看结果                       |
| 未完成        | 操作未成功完成，可按页面指引再次操作             |

## 技术信息的用户表达

普通用户只应看到业务影响和可执行的下一步，不显示内部实现、英文错误码或原始返回内容。

| 内部情况               | 普通用户显示                                     |
| ---------------------- | ------------------------------------------------ |
| 登录失效或身份校验失败 | 登录状态已失效，请重新登录。                     |
| 无权访问当前数据       | 你没有权限查看或操作这项内容。                   |
| 数据不存在             | 未找到相关内容，可能已被删除。                   |
| 操作过于频繁           | 操作过于频繁，请稍后再试。                       |
| 套餐或额度不足         | 当前可用次数不足，请查看套餐与额度。             |
| 输入校验不通过         | 请检查填写内容后再试。具体字段使用对应中文提示。 |
| AI 返回内容无法识别    | AI 返回内容暂时无法识别，请重新生成。            |
| 服务暂时不可用         | 服务暂时不可用，请稍后再试。                     |
| 网络超时               | 处理时间较长，请稍后重试。                       |
| 未知系统错误           | 操作未完成，请稍后再试。                         |

## 空状态规范

空状态必须说明当前状态和下一步行动。例如：

- 还没有主体档案：创建主体档案后，即可开始关键词和检测工作。
- 还没有关键词资产：先添加关键词并完成蒸馏，确认后会出现在这里。
- 还没有正式问题：从关键词资产生成问题并保存后，可在这里管理。
- 还没有检测报告：选择问题并完成一次 AI 可见度检测后即可查看报告。
- 还没有文章：生成文章并保存到内容库后，可在这里统一管理。

禁止只显示“暂无数据”“No data”或没有行动建议的空白页。

## 必须隐藏的内容

普通用户界面不得出现开发、接口、运维和内部协作术语，包括但不限于英文运行状态、内部编号、请求与返回结构、密钥与凭据、部署环境、数据格式、异常堆栈、缓存和数据库信息，以及“待开发、暂未接入、先占位、以后补、第一阶段、MVP”等内部进度文案。

GEO、SEO、AI、已经面向用户公布的模型品牌名称，以及 PDF、PNG、JPEG、WEBP、Word、Excel、KB、MB、GB 等通用文件格式和容量单位可保留，因为它们属于用户选择和理解功能所必需的行业或产品名称。

## 实施约束

- 用户端错误统一通过 `frontend/lib/product-copy.ts` 映射，不能直接展示服务端原始错误信息。
- 新增普通用户页面或组件后必须运行 `npm run audit:copy`。
- 中文文案审计只扫描普通用户页面；管理后台按其职责单独审查。
- 审计通过不代表文案质量天然合格，仍需在功能验收时检查空状态、下一步指引和上下文是否自然。
