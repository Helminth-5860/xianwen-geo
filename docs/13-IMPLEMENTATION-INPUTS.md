# 13. 开发实施所需账号、资料与外部输入

本清单不是新的产品问题，而是开始真实集成和上线前必须准备的实施材料。

## 1. 品牌与网站

- 显问正式中文名称
- 显问 Logo（横版、方形、透明 PNG／SVG）
- 品牌主色和辅助色
- 默认报告封面素材
- 联系电话、微信、客服说明
- 正式域名和 DNS 管理权限
- 用户协议、隐私政策、内容规则文本

## 2. 8 模型

每个模型提供：

- 官方 API 文档地址或离线文档
- 账号／项目标识
- 生产 API 密钥（仅在超级管理员或密钥管理中录入）
- 实际模型 ID
- 是否支持联网及参数
- 引用返回示例
- 并发、QPS、Token、计费和错误码
- 商用和内容审核限制

## 3. DeepSeek 内容与评分

需要确认：

- 关键词、蒸馏、问题库、策略、文章、质量、助手可用的模型 ID
- JSON Schema 输出能力
- 最大上下文和输出长度
- 价格与并发
- 是否有联网能力；文章检索仍以系统资料包为主

当前未完成开通／验收。

## 4. 豆包图片

需要确认：

- 文生图模型 ID
- 支持尺寸
- 参考图能力
- 扩图／重构能力
- 同步或异步接口
- 内容审核返回
- 临时结果 URL 有效期
- 价格和并发

当前未完成开通／验收。

## 5. 腾讯云 COS

需要创建：

- 生产私有桶
- 测试私有桶
- 跨域规则
- 生命周期规则
- 应用最小权限子账号或角色
- 备份桶／异地策略

## 6. 短信

需要准备：

- 短信应用
- 签名
- 注册／登录验证码模板
- 审核结果模板
- 账号安全模板
- 套餐到期模板
- 严重告警模板

## 7. 内容审核

需要确定使用：

- 模型供应商内置审核
- 独立文本／图片审核服务
- 管理员人工审核角色和工作时间

## 8. 运维

- 生产服务器 SSH 管理方式
- 数据库只读／应用账号
- Redis 连接和证书
- 备份对象存储
- 告警短信接收超级管理员手机号
- 监控平台账号
- CI/CD 仓库和部署凭证

## 9. 测试数据

至少准备：

- 3–5 种主体类型样例
- 每种主体的完整资料、别名和唯一产品
- 关键词／问题库黄金样本
- 评分边界回答样本
- 正常和违规文章／图片测试样本
- 公开发布链接成功、失败、登录限制样本

## 10. 录入纪律

- 密钥不得通过聊天、文档、截图或 Git 传递。
- Codex 使用 Mock 值和环境变量名。
- 真实密钥由授权超级管理员在受控环境录入。
