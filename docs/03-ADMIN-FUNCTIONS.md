# 03. 后台管理员功能需求

## 1. 后台设计原则

- 超级管理员拥有全系统最高权限，但敏感凭证仍不可在保存后重新查看明文。
- 普通管理员权限由自定义角色控制，禁止仅按页面隐藏实现权限。
- 所有高风险操作必须有审计记录。
- 套餐、额度、模型和提示词配置均必须版本化或保留变更快照。
- 后台不记录线下收款、成交金额、退款、发票或财务凭证。

## 2. 管理员与角色

### 2.1 管理员账号

字段：

- 姓名／昵称
- 登录账号或手机号
- 状态：启用、停用、锁定
- 所属角色
- 是否强制短信二次验证
- IP 白名单策略
- 最近登录时间、IP、设备

### 2.2 自定义角色

超级管理员可：

- 新增、编辑、停用角色
- 配置菜单权限
- 配置操作权限：查看、创建、编辑、删除、审核、导出、额度调整、任务取消等
- 配置客户可见范围：仅本人负责、角色范围、全部客户
- 配置是否需要短信二次验证
- 配置 IP 白名单

角色被使用后不可物理删除，只能停用。

### 2.3 超级管理员固定权限

- 管理所有管理员与角色
- 管理 API 密钥
- 管理全站模型配置
- 发布提示词版本
- 配置高风险审批规则
- 配置全站并发、成本、备份和告警
- 执行强制只读用户视角查看
- 查看全量审计日志

## 3. 高风险操作与审批

### 3.1 安全等级

每种高风险操作可配置为：

1. 普通二次确认
2. 管理员密码验证
3. 双人审批

### 3.2 默认双人审批操作

- 删除用户、主体或管理员
- 批量扣减或清零额度
- 批量修改用户套餐
- 修改 GEO 评分规则或评分版本
- 查看／替换 API 密钥相关配置
- 导出全量客户或业务数据
- 批量清理文件、文章或报告
- 关闭核心模型或全站 API
- 修改高风险角色权限

发起人不得审批自己的申请。

### 3.3 审批记录

保存：发起人、审批人、操作对象、变更前后数据、理由、时间、IP、设备、审批结论和最终执行结果。

## 4. 工作台与运营总览

后台首页展示：

- 新增用户、待审核用户
- 试用中、正式客户、即将到期、已到期用户
- 当前活跃用户和近 7／30 天活跃趋势
- GEO 检测任务量、成功率、排队量
- 各模型调用量、成功率、耗时、估算成本
- 文章、图片、关键词和问题库使用量
- 待人工审核内容
- 待处理用户反馈
- 今日客户跟进待办
- 严重系统告警

不展示收入、成交额、应收或退款等财务数据。

## 5. 用户注册与账号管理

### 5.1 用户列表

筛选：手机号、昵称、审核状态、账号状态、套餐、客户状态、负责人、注册时间、最近活跃时间。

可查看：

- 基本账号资料
- 审核记录
- 当前套餐和额度
- 主体数量和状态
- 使用情况
- 登录和安全记录
- 套餐申请
- 客户标签与联系记录
- 注销状态

### 5.2 注册审核

操作：

- 审核通过
- 审核通过并发放试用套餐
- 审核拒绝并填写原因
- 用户修改后重新审核
- 冻结／解冻

试用套餐立即生效并从发放时间计算有效期。

### 5.3 安全操作

- 强制退出全部设备
- 重置密码流程（不得显示或设置可见明文密码）
- 查看异常登录
- 临时锁定账号
- 查看历史注销记录

## 6. 套餐管理

### 6.1 套餐生命周期

- 新建草稿
- 发布／上架
- 下架
- 复制套餐
- 创建新版本

已开通用户必须绑定开通时的套餐权益快照，后台修改套餐不应追溯改变历史用户权益。

### 6.2 套餐字段

具体限制键见 `05-QUOTA-BILLING-RULES.md` 和 `config/plan-limit-keys.json`。

至少包括：

- 套餐名称、说明、展示价格
- 有效天数
- 主体数量
- 可用模型列表
- 检测点
- 单次检测问题上限
- 用户并发检测任务数
- 队列优先级
- 文章额度、图片额度
- 关键词／蒸馏／问题库重新生成次数
- 改善策略重新生成次数
- 大纲重新生成次数
- 局部 AI 修改次数
- 质量复检次数
- AI 助手对话次数
- 存储空间
- 白标权限
- 业务记录保留期
- 主体／图片／资料回收站期限
- 套餐到期额度处理方式

### 6.3 用户套餐开通与变更

管理员可：

- 开通试用／正式套餐
- 选择生效时间和到期时间
- 选择旧额度处理：覆盖、累加、保留
- 试用转正式时选择：覆盖、累加、顺延
- 续费或降级
- 填写经办备注

同一账号同一时间只允许一个生效套餐。

## 7. 套餐申请管理

列表字段：用户、目标套餐、联系人、联系电话、备注、提交时间、负责人、状态。

状态：待处理、已联系、已开通、已关闭。

管理员可填写处理备注；开通套餐后自动标记“已开通”。

## 8. 额度管理

### 8.1 用户额度视图

展示：

- 当前可用
- 已冻结
- 本周期已用
- 下次重置时间
- 到期处理规则
- 历史流水

### 8.2 管理员操作

允许通过流水执行：

- 赠送
- 补偿
- 扣减
- 冻结／解冻
- 返还
- 周期重置
- 套餐迁移

禁止直接编辑余额数字。

### 8.3 批量操作

批量补偿和扣减必须支持预览、数量校验、审批和导入结果报告。

## 9. 客户记录（轻量 CRM）

### 9.1 客户档案

- 手机号、昵称
- 注册／审核／套餐状态
- 客户来源渠道
- 客户标签
- 客户状态
- 唯一主负责人
- 内部备注
- 最近活跃情况
- 套餐和额度使用概览

### 9.2 客户状态

内置：待审核、审核未通过、待开通、试用中、正式客户、即将到期、已到期、暂停使用、已流失、已注销。

后台可新增、修改、排序和停用；已被使用的状态不可删除。

### 9.3 联系记录

保存：联系时间、方式、内容、管理员、下次跟进时间。

### 9.4 跟进提醒

- 后台待办列表
- 站内提醒客户负责人
- 今日、逾期和未来待办
- 可完成、延期或取消

不发送短信。

### 9.5 负责人分配

每个客户仅一个负责人。转交时记录原负责人、新负责人、操作人、时间和原因。管理员停用前必须转移客户。

## 10. 主体类型与字段管理

### 10.1 主体类型

- 新增、编辑、排序、启停
- 配置说明、图标、风险类型
- 配置关键词、问题库、改善策略和文章生成提示词模板

### 10.2 字段配置

支持字段类型、必填、默认值、选项、排序、参与生成、有效名称和产品字段标记。

V1 不做字段间条件显示逻辑。

### 10.3 风险规则

- 新增、启停风险类别
- 配置命中规则
- 配置可用功能和审核强度
- 配置强制引用、禁用文章类型、免责声明等

## 11. 主体审核

后台待审核队列包括：

- 疑似违规
- 疑似冒用
- 资料冲突
- 高风险行业

管理员可通过、驳回并说明原因。审核通过后按风险类型限制功能。

## 12. 模型与 API 管理

### 12.1 模型范围

固定 8 个检测模型；普通管理员不得新增自定义模型。

### 12.2 可配置项

- 显示名称和排序
- 启用／停用
- 接口版本、模型 ID
- 是否支持联网
- 联网失败策略
- 超时、重试次数、重试间隔
- 每模型并发上限
- 调用频率限制
- 成本单位和单价
- 成本预警阈值和最高限额
- 达限策略：仅预警／自动暂停
- 恢复策略：手动／下周期自动

### 12.3 API 密钥

仅超级管理员可进入。

- 新增时显示一次明文
- 保存后只显示掩码
- 不允许再次查看原文
- 替换时输入新密钥
- 新密钥测试通过后切换
- 密钥加密保存
- 所有操作审计

### 12.4 模型暂停

自动暂停后：

- 新任务不显示该模型
- 已排队未调用的任务取消并返还点
- 已在调用中的请求允许完成
- 不自动替换其他模型

## 13. 系统测试额度

独立于用户套餐。

- 全站总测试额度
- 每个模型独立上限
- 每日或每月周期
- 记录模型、输入、输出、Token、成本、耗时、结果、操作者
- 达上限停止测试

用于 API 测试和提示词测试。

## 14. 任务中心

### 14.1 任务类型

- 主体资料补充
- 关键词生成
- 关键词蒸馏
- 问题库生成
- GEO 检测
- GEO 评分和报告
- 改善策略
- 文章、大纲、局部优化、整篇优化
- 质量检测
- 图片生成和智能处理
- 文件解析
- 报告导出
- 发布链接检测

### 14.2 管理能力

- 查看状态、进度、耗时和重试
- 按用户、主体、模型、类型、时间筛选
- 取消等待任务
- 重试系统失败任务
- 查看失败原因
- 手工补偿额度
- 查看队列积压和并发

重试必须保证幂等，不得重复扣额度。

## 15. GEO 报告管理

管理员可只读查看：

- 检测快照
- 原始问题和模型回答
- 引用来源
- 六维评分和判断依据
- 综合分、口碑分、曝光指数
- 失败模型和调用日志
- 评分规则和提示词版本

管理员不得修改检测分数或原始回答。

## 16. 文章与图片审核

### 16.1 审核队列

- 文章疑似违规
- 图片疑似违规
- 用户人工复核申请

### 16.2 审核操作

- 通过
- 驳回并选择违规类别
- 判断是否为系统误判
- 按责任触发额度返还或不返还
- 超级管理员额外开放再次复核

所有审核记录不可删除。

## 17. 文章类型、质量规则与渠道模板

### 17.1 文章类型

后台可配置：名称、说明、适用主体类型、提示词、默认结构、是否需要标题／摘要／标签、引用要求、联网策略、可用资料范围、推荐渠道。

### 17.2 质量规则

V1 固定权重，后台仅查看和版本管理，不提供随意改权重入口。如后续调整，必须创建新质量规则版本。

### 17.3 发布渠道

配置：名称、Logo、官网、类型、适用文章／主体、说明、图片比例、外链要求、启停和排序。

### 17.4 渠道适配模板

版本化配置标题、结构、语气、摘要、标签、话题、图片和外链规则。

## 18. 图片尺寸与风格预设

### 18.1 尺寸

- 名称
- 宽高比
- 像素
- 豆包参数
- 适用渠道和用途
- 启停和排序

### 18.2 风格

- 名称、说明
- 提示词模板
- 适用主体／文章／渠道
- 推荐比例
- 示例图
- 启停和排序

## 19. 问题分类管理

管理员可新增、修改、排序、停用问题分类，并配置适用主体类型和生成说明。已被使用的分类不可删除。

## 20. 提示词版本管理

### 20.1 模板范围

- 主体资料补充
- 关键词生成
- 蒸馏
- 问题库
- GEO 评分语义分析
- 改善策略
- 文章大纲和正文
- 质量检测
- 图片提示词辅助
- AI 助手

### 20.2 生命周期

- 草稿
- 测试中
- 已发布
- 已停用

新版本先作为草稿，超级管理员测试通过后手动发布。发布仅影响新任务。

### 20.3 测试方式

- 固定测试案例
- 手动输入
- 选择历史任务的脱敏副本
- 新旧版本结果对比
- 使用系统测试额度

## 21. 公告与站内消息

### 21.1 公告

发布范围：全部用户、指定套餐、指定账号。

配置：标题、正文、开始／结束时间、置顶、启停。

### 21.2 通知模板

管理站内消息和短信模板。短信只用于验证码、审核、账号安全和套餐到期。

## 22. 用户反馈

列表和详情：用户、主体、模块、描述、截图、状态、管理员回复。

状态：待处理、已回复、已关闭。

## 23. 管理员协助查看

### 23.1 普通协助

- 管理员发起只读查看申请
- 用户站内授权
- 授权仅一次会话
- 退出、超时或用户撤销后失效

### 23.2 强制查看

仅超级管理员用于账号安全、违规调查或系统故障。必须填写原因，完成后通知用户。

只读查看禁止：修改、导出、复制敏感信息、调用 API、消耗额度。

## 24. 数据统计与导出

可按时间、用户、主体、套餐、模型、负责人和功能筛选：

- 注册、审核、活跃和留存
- 套餐开通和到期
- 检测点使用
- GEO 分数分布
- 各模型调用量、成功率、耗时和成本
- 文章、图片和其他功能使用量
- 客户跟进
- 任务失败和审核量

支持 Excel／CSV 导出。全量客户或业务数据导出默认双人审批。

## 25. 使用日志与审计

### 25.1 业务使用日志

保存用户、主体、功能、模型、状态、耗时、重试、额度变化、成本、IP、设备和失败原因。

### 25.2 审计日志

保存管理员高风险操作、审批、密钥操作、套餐变更、额度变更、数据导出、用户视角查看、删除和恢复。

审计日志不可由普通管理员删除。

## 26. 系统配置

- 站点名称和显问品牌素材
- 功能开关
- 维护模式
- 全站任务最长排队时间
- 全站总并发
- 登录失败锁定策略
- 管理员会话超时
- 数据保留规则
- 告警分级和通知渠道
- 文件上传限制
- 内容审核规则

## 27. 备份、恢复与告警

### 27.1 备份

超级管理员配置：

- 每日增量／每周完整默认策略
- 数据库和对象存储备份
- 本地近期备份、独立对象存储、跨云／异地重要备份
- 加密、保留期和自动清理
- 恢复有效性测试

### 27.2 RPO／RTO

按数据类型配置，不使用全站单一标准。

### 27.3 告警等级

- 普通：后台看板
- 重要：后台＋站内消息
- 严重：后台＋站内消息＋短信

严重告警包括数据库不可用、备份连续失败、API 密钥失效、额度流水异常、对象存储故障和核心模型全部不可用。

## XW-0304 已实现：问题分类后台

- 管理员可创建、编辑、排序、启用和停用问题分类与辅助标签，并配置适用主体类型。
- 内置十类问题分类使用稳定 key；需求未定义内置辅助标签，因此不预置标签。
- 稳定 key 创建后不可修改；空适用主体表示全部主体；目录项不提供删除操作。
- 分类可维护供后续问题生成使用的纯文本生成说明，但 XW-0304 不调用 AI、不生成问题库。
- 所有写操作要求对应 capability、CSRF 与 expected_version；审计只记录安全摘要。
